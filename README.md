# Onuldo (오늘도)

> 오늘도, 나를 위해 한 걸음  
> 취미 활동을 기록하고 공유하는 타이머 기반 기록 앱

---

## 📱 서비스 소개

**Onuldo**는 운동, 공부, 연습, 창작 등  
어떤 취미든 **시간을 재고 → 기록하고 → 공유하며 → 응원받을 수 있는**  
취미 기록 중심 모바일 애플리케이션입니다.

단순한 SNS가 아닌,  
**실제 활동 데이터를 기반으로 한 기록과 성장 경험**을 제공하는 것이 목표입니다.

---

## ✨ 주요 기능

### ⏱️ 타이머 기반 취미 기록
- 취미 선택 후 타이머 시작
- 일시정지 / 종료
- 수동 기록도 지원

### 📝 기록 작성
- 활동 시간 자동 저장
- 메모 작성
- 사진 업로드
- 태그(#운동 #공부 #연습)
- 공개 범위 설정 (전체 / 팔로워 / 나만)

### 📰 SNS 피드
- 팔로잉 / 전체 피드
- 취미 / 태그 필터
- 최신순 / 인기순 정렬

### ❤️ 반응 & 소통
- 이모지 리액션 (❤️🔥👏 등)
- 댓글 / 대댓글
- 알림 제공

### 📊 성장 리포트
- 일/주/월 활동 통계
- 취미별 누적 시간
- 연속 기록 스트릭
- 캘린더 기반 기록 보기

- 경쟁보다 **꾸준함**
- 비교보다 **기록**
- 자극보다 **응원**
